# ── On-screen text recognition (OCR) ──────────────────────────────────────
# Reads text off a paused frame in the review player and offers it as a
# subtitle cue. Three packages, ~71 MB of wheels:
#
#   onnxruntime            runs the detection and recognition models
#   rapidocr-onnxruntime   PaddleOCR DB detection + its post-processing,
#                          with the detector model (4.5 MB) inside the wheel
#   opencv-python          image ops (arrives with rapidocr; named for clarity)
#
# CPU deliberately: a paused frame costs a few hundred milliseconds, while
# onnxruntime-gpu would add ~200 MB and a second consumer of cuDNN, whose
# version is already pinned differently between the default and Pascal
# CUDA builds. Recognition models (3-11 MB each, Apache-2.0) download on
# first use into models/ocr/.
#
# rapidocr-onnxruntime is PINNED: its return shape has changed across the
# 1.x line and the 2.x/3.x packages are a different API entirely.
onnxruntime>=1.16
rapidocr-onnxruntime==1.4.4
opencv-python>=4.5.1.48
rich>=13.0.0

# Why no torch here
# -----------------
# Transcription runs on CTranslate2 (via faster-whisper) end to end.  Torch
# was previously a hard dependency used for exactly one thing: calling
# torch.cuda.is_available() in the GPU probe.  That cost every user a ~2.5 GB
# download — including CPU-only users who could never benefit from it, and
# users on metered or expensive connections.  gensrt/gpu_probe.py now asks
# CTranslate2 instead, which is both smaller and a more accurate answer,
# since CTranslate2 is what actually runs the model.
#
# As of v1.2.5 nothing in GenSRT uses torch at all: the torch-based offline
# translation engines were removed. v1.2.7 brings offline translation BACK —
# NLLB-200 on CTranslate2 — still with no torch and, in fact, no new
# dependencies at all: ctranslate2 runs the model, tokenizers (which arrives
# with faster-whisper) reads the model's tokenizer.json, and huggingface_hub
# (likewise) performs the one-time model download.
